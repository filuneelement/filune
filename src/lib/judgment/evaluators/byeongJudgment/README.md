# 병 후보와 최종 판정

A179 A-8-2 ⑥은 확정 격국·용신·상신 입력을 소비한다. 원국용 기존 판단을 현재 운에서 사용할 때는 원국 scope의 역할과 현재 scope의 기능 상태를 함께 전달한다. 지지 상신은 기존 `RoleStateContract`의 평가 결과를 연결할 수 있다. 현재 상신 evaluator는 지지 상신을 산출하지 않으므로 그 결과는 상류에서 공급해야 한다.

- `evaluateByeongCandidates`는 보호 대상, 위치별 entity, 상태, 조사 완료 여부, 관계 관측, 증거와 provenance를 보존한다.
- `evaluateByeongJudgment`는 전달된 후보의 참조와 관측을 검증한다. 실제 손상 관측이 확인된 entity에 병 역할을 하나씩 만들고, 여러 경로는 trace에 남긴다.
- `I-03`이 병 역할의 정의를 제공하고, `I-04-2`가 식신격에서 실제 식신 손상을 확인하는 경로를 제공한다. 식신격의 지지 보호 대상은 확정 격국의 원국 월지다. 인성 여부, 조사 범위와 실제 극·손상은 검증된 `FoodDamageReview` 및 경로 증거로 전달한다. 단순 오행 관계, 십성 명칭, 지지의 해만으로 손상을 만들지 않는다.
- 기존 관계 catalog에는 방향성 있는 지지 극이 없으므로 branch 관련 실제 관계·손상은 별도 관측 근거가 필요하다. 기존 Relation Fact가 제공되면 방향, 조사 범위, 평가와 근거를 대조한다. 관측을 공급하는 새 명리 규칙이나 producer는 이 변경에 포함되지 않는다.
- `issueByeongRuleReceipts`는 고정된 A179 원문 바이트에서 실행 조항을 확인한다. 운영 입력에서는 관측 증거의 claim을 `foodDamageReviewClaim`과 `foodDamagePathClaim`으로 묶는다. 확정 증거가 조사 범위와 관측 내용에 연결돼야 한다. 회귀 기대값은 verify에서만 대조한다.
- 성립에는 해당 상태에서 입증된 손상이 필요하다. 약화 상태는 그대로 유지하며 새 정량 임계값을 두지 않는다. 합거된 원국 병은 기존 역할과 provenance를 보존하고 현재 작용을 정지한다. `I-04a`와 `I-04c` 적용 근거는 별도로 전달한다. 다른 격국·상신 손상의 종합은 `unassessed`다.
- `no-byeong`은 지원 규칙과 해당 실행 범위 전체에 대해 조사 완료 및 손상 배제가 입증된 경우에만 반환한다. 실행 규칙·근거 부족은 `deferred`다. 확정 병이 있으면 `has-byeong`을 반환하고 보류 후보도 함께 보존한다.

`npm run verify:byeong-contract`의 CS-127 합성 fixture는 상류에서 확인된 역할과 방향성 있는 기능 관측을 공급하는 계약 테스트다. 실제 원국 입력부터 지지 손상까지 자동으로 생산하는 검증은 추가 상류 지원이 필요하다.

## A rev180 draft 재검증

- `npm run verify:byeong-regression`은 출생 입력에서 canonical 및 기존 격·용신·상신 evaluator를 실행한다. draft 평가에 `FoodDamageReview`를 공급하면 거부한다. 이 검증은 세 명식의 `deferred` 동작을 검증한다. CS-127의 未·戌 양성 독립 산출은 미확보다.
- `npm run verify:byeong-contract`은 합성 손상 관측과 상태를 공급하는 계약 테스트다. `has-byeong`, `no-byeong`, `deferred`를 각각 검증한다.
- draft 경로는 A-8-2 ⑥의 6~8항에 필요한 선행 사실과 부족 근거를 기록한다. 식신격의 방향성 있는 지지 극, 보호·제어 이후 손상, 재생살 이후 잔존 손상과 귀속은 공급하거나 독립 산출할 수 있는 근거가 필요하다. 지지의 일반 관계 Fact를 지지 극이나 손상으로 해석하지 않는다.

### 지지 본기 관계 관측

`produceBranchMainRelations`는 canonical 본기·십성 Fact를 문서 지장간 관측과 대조하고, 기존 천간 오행 극 판별을 본기 쌍에 적용한다. 원국 지지마다 출발·도착 방향을 구분하고 역할, 상태 참조, 근거와 provenance를 남긴다. 문서 본기가 확인되지 않은 canonical 관측은 잠정으로 유지한다.

CS-127에서 戌→子의 본기 극은 확정 구조 관측이고, 未→子의 본기 극은 잠정 구조 관측이다. 이 Fact의 종류는 `main-hidden-stem-controls`다. 실제 지지의 기능적 극이나 I-04-2 손상 Fact로 승격하는 조건은 별도로 필요하다. 현재 원국 상태 evaluator에서 지지 상태를 제공하지 않으므로 해당 상태 참조는 비어 있다. 상신·통관·잔존 손상도 독립 확인될 때까지 병과 병 없음의 확정을 보류한다.
