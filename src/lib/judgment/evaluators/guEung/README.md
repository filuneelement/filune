# GuEung v1

`evaluateGuEung` validates the existing 병 boundary, supplied candidate/relationship links, scoped runtime states, and independently attested effect facts. Each confirmed link retains its effect Fact reference and evidence. A complete local no-effect rejects only that candidate/path. Overall `no-gu-eung` is reserved pending an independent global coverage contract.

The effect receipt binds its deterministic producer to the exact effect payload. Evidence with regression-expectation lineage, unconfirmed evidence, missing individual attribution, and unsupported mechanisms cannot confirm a role. The existing boundary schema still accepts only routing outcomes. The separate v1 result schema validates confirmed effects and their role/application links.

`produceStemPathEffects` is the structural bridge for the existing luck-to-natal `OP-T07` stopping result. It requires an independently attested necessary-source dependency, a matching pre-stop state, and the verified stopping event. It describes the termination of that one damage path and does not create a role. The caller provides effects, candidates, and links to the evaluator. There is no production dependency inference in this change.

The v1 contract verification includes a real stem-combination result with a synthetic damage/dependency handoff. That verifies the bridge contract and is not a positive CS regression. No CS expected role/effect is used at runtime.
