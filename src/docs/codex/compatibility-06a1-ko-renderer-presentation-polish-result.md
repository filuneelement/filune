## 표시 계약

KO 렌더러는 C5의 기준 시각과 확정 Gregorian 경계를 반개구간으로 비교한다. 기준 시각 앞뒤를 걸치고 시작 시각의 달력상 1주년을 넘는 구간은 **현재를 포함한 장기 흐름**으로 표시한다. 그보다 짧은 활성 구간은 **현재**로 표시한다. 날짜 라벨은 서울 시간으로 표시한다. 달력 경계가 제공되지 않은 판정은 **달력 시점 미확인**으로 유지한다.

동일 의미·방향·인물·문구 변형은 기존 구간과 출처 ID를 묶어 한 문장으로 표시한다. 동일한 시각 경계는 하나의 카드로 묶고, 중첩된 하위 구간에는 상위 기간과 그 출처를 연결한다. 상호 공식화 구간은 개인의 전체 흐름 안에 놓아 보여 준다. 카드 안의 결혼 기회·주의, 관계 부담·파탄 위험은 독립된 설명을 갖는다.

시기별 보기는 현재 포함 구간, 미래, 과거, 달력 시점 미확인 순으로 표시한다. 날짜가 있는 미래는 시작 시각순이다. 두 사람의 영향 방향, 명시 이름과 관계 상태의 사용 조건, headline 의미, C1–C5 및 C6-A 확정도와 위험의 강도를 보존했다.
