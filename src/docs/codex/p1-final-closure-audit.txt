수정 결과

LK-072 — 합거의 유효기간
유효기간은 시작 시각을 포함하고 종료 시각을 제외한다. 코어가 만료된 운을
직접 입력받아도 합거 관계·공식은 이력에 남고 런타임에는 반영되지 않는다.
현재 유효한 별도 정지 원인이 없다면 천간과 역할 상태는 현재 근거로 재평가한다.
유효기간 안의 합거는 기존 정지를 유지한다.

SG-174 / EX-140 — 운 이벤트 수명주기
luckEffects는 해당 scope에서 새로 발행된 이벤트, luckEffectHistory는 발생 이력,
luckEffectStates는 현재 유효 여부를 보여준다. 세운·월운·일진에서도 동일 이벤트 ID와
발생 scope·기간을 보존하고, 원인이 끝나면 currentlyEffective=false / expired=true가 된다.
독립된 다음 리딩으로 이력을 넘길 때는 priorHistory에 앞선 스냅샷을 전달한다.
월운 윈도우는 이력을 자동 승계하고 현재 상태는 매 기간의 입력으로 계산한다.
만료된 운이 코어에 직접 주어지면 해당 기간의 마지막 유효 시점으로 이력을 재구성한다.
