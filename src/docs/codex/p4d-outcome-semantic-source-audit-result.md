## B. Source coverage 및 후보 규칙

분류는 행 단위다. **Explicit**는 원문이 조건과 의미를 직접 연결한 한정 후보다. **Inference**는 반복 문맥으로 찾은 후보이며 현재 코드·고객 판정으로 승인되지 않았다. **Override**는 이미 확인된 FILUNE 운영 제약이다. **Conflict**는 출처에 존재하는 충돌 표현을 기록한 것이며 해당 출력을 허용하지 않는다. **Deferred**에는 B 요구만 있거나 실제 조건·결과의 연결이 빠진 항목을 넣었다. 숫자는 전문가 사례 수를 뜻하지 않는다.

[07 원문](../source/primary/07-사주풀이예시.md) 1–3348행을 원국표·주제절 경계로 나눴다. 각 칸은 예시·사례·일반 해설의 후보 검색 행이다. 재성이 부모를 뜻하거나 병이 구조 역할을 뜻하는 등의 히트는 분야 결과를 지지하는 사례로 간주하지 않았다. 위 표에서 판정에 영향을 준 문맥과 반례를 별도로 제시했다. 3206행 이후 두 명식 사례는 범위 구분과 반례의 근거다.

검색 축은 일·직업·직장·사업·조직·독립·성과·교육·자문·기술·공무원·관리·전문과 취업/이직/프리랜서, 돈·재성·계약·재산·투자·문서와 손익/유입/분탈, 배우자·인연·혼인·가족과 육친/궁합, 건강·몸·질병과 장기/신체 표현이다. 짧은 글자(일·간·위·폐 등)는 단어 용례와 인접 문맥을 대조했다. 인덱스는 배치를 위해 결합 표현과 관련 동의어 hit를 표시한다.
