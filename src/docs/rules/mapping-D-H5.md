# D rev152 H-5 테스트 구조 매핑

CT = 계산 단위 예외 테스트 / RT = 규칙 단위 합성 테스트 / NT = 신규 명식 통합 테스트 / ST = 고객 문장 품질 테스트. 영문 약어 풀이는 만들지 않는다. 회귀 고정 사례는 별도 계층 4이며 RT의 R을 회귀로 해석하지 않는다.

## 누락·주의

원문에는 각 유형별 목적/입력/실패 조건이 한 표에 정규화되어 있지 않다. 위 실패 조건은 H-4 합격 조건 미충족이라는 검증상 표현이며 새 명리 규칙이 아니다. NT의 길흉을 새 기대값으로 만들지 않는다. 회귀는 C-10·25-7 ⑤의 축별 고정값만 사용한다. H-5-1의 B 범위는 문장·장 구성이고 A 판정으로 편입하지 않는다.
