FILUNE v1 비견격·겁재격·양인격 마스터 규칙 v0.2
0. 문서의 지위
이 문서는 FILUNE v1에서 다음 비겁계 특수격을 판정하기 위한 실행 기준이다.
•	비견격
•	겁재격
•	양인격
이 세 격은 모두 월령이 일간과 같은 오행 계열이라는 공통점이 있지만, 실제 판정 공식은 서로 다르다.
따라서 FILUNE에서는 세 격을 하나의 록겁격 코드 규칙으로 합치지 않는다.
________________________________________
1. 세 격을 하나로 합치지 않는다
BG-001
비견격
비견의 강한 자기기반과 독립성을 어떤 사회적 기능으로 연결하는지가 핵심이다.
겁재격
재성 분탈성이 강하므로:
•	관성 제어
•	재성 보호
•	식상 통관
이 중요하다.
양인격
겁재보다 더 강한 자기세력·분탈 구조로 보며 관살에 의한 제어가 핵심이다.
따라서:
peer_pattern
rob_wealth_pattern
yang_blade_pattern
을 별도로 유지한다.
________________________________________
2. 비견격 성립
BG-010
월령 대표 기운이 일간과:
•	같은 오행
•	같은 음양
이면 지지 비견격으로 본다.
단 양간의 월령이 FILUNE 양인 조건에 해당하면 양인격을 우선한다.
________________________________________
3. 겁재격 성립
BG-011
월령 대표 기운이 일간과:
•	같은 오행
•	다른 음양
이면 기본적으로 겁재격으로 본다.
단 FILUNE 양인 조건을 만족하면 겁재격이 아니라 양인격으로 별도 처리한다.
________________________________________
4. 양인격 성립 — FILUNE 확정
BG-012
FILUNE v1에서는 전문가 실제 풀이 기준에 따라 다음 네 경우만 양인격으로 인정한다.
•	甲日 卯月
•	丙日 午月
•	庚日 酉月
•	壬日 子月
전문가 풀이 자료는 실제 판정에서 이 네 조합을 양인격으로 사용하며, 戊午는 12운성상 제왕이라도 정인격으로 처리한다.
따라서:
戊午 = 羊刃格
으로 처리하지 않는다.
________________________________________
5. 격국론과의 충돌
격국론 자료에서는 戊午도 火土同根을 이유로 양인에 포함하는 설명이 있다.
FILUNE APPROVED OVERRIDE
FILUNE v1에서는 실제 전문가 풀이 체계를 우선하여:
甲卯·丙午·庚酉·壬子
네 경우만 양인격으로 고정한다.
________________________________________
6. 지지 격과 천간 용신을 분리한다
BG-020
비겁계 특수격에서도:
지지 격
과
천간 YongShen
을 분리한다.
예:
乙日 寅月이면 지지에서는 겁재격이다.
그러나 천간에서는 寅의 비겁 성분 자체를 주용신으로 쓰지 않고, 지장간의 다른 사용할 수 있는 성분이 천간에 투출하는지를 본다.
________________________________________
7. 월령 비겁 성분은 천간 주용신으로 사용하지 않는다
BG-021
비견격·겁재격에서 월령의 비겁 성분이 천간에 다시 투출했다고 해서 자동 YongShen으로 삼지 않는다.
특히 겁재·양인 구조에서는 비겁의 추가 투출이:
•	자기세력 강화
•	재성 분탈 증가
로 작동할 수 있다.
따라서:
月令 比劫
+
天干 比劫
→ 자동 YongShen 금지.
________________________________________
8. 월령무용
BG-022
월령 지장간에서 비겁 외의 사용할 성분을 얻을 수 없는 경우 월령무용으로 처리할 수 있다.
전문가 자료는 이런 경우:
관 → 재 → 인 → 식
순으로 가용신을 검토한다고 설명한다.
단 비겁계 특수격에서는 아래의 격별 FILUNE 규칙이 일반 가용신 순서보다 우선한다.
________________________________________
9. 비견격의 기본 성격
BG-030
비견은:
•	자기 힘
•	독립
•	동료
•	경쟁
•	자기 기반
과 연결된다.
비견은 겁재·양인보다 재성 분탈성이 상대적으로 약하다.
따라서 비견격에서는 강한 자기기반을:
•	정관
•	재성
•	필요한 식상
등을 통해 실제 사회적 기능으로 연결하는 것이 중요하다.
________________________________________
10. 비견격의 FILUNE 주용신
BG-031 FILUNE APPROVED
비견격에서는 칠살을 주용신으로 사용하지 않는다.
기본 중심:
1. 정관
비견의 자기세력을 질서·직위·책임으로 연결할 수 있다.
2. 재성
비견의 힘을 현실 성과와 재물 기능으로 연결할 수 있다.
식상
보조적으로 사용한다.
•	비견 설기
•	재성 생조
•	통관
•	칠살 문제 제어
인성
필요한 경우 사용할 수 있으나 이미 강한 일간·비견을 더 강화하는지 확인한다.
________________________________________
11. 비견격에서 칠살
BG-032
FILUNE v1에서는:
比肩格 → 七殺 YongShen
공식을 사용하지 않는다.
칠살이 존재하면:
•	병인가
•	식상으로 제살되는가
•	인성으로 잘못 살리는가
•	일간이 감당 가능한가
를 별도로 판단한다.
전문가 풀이 자료에서도 월건록/비견격에서 칠살 문제를 인성으로 해소하는 것을 살인상생으로 긍정하기보다, 식신제살 방향이 더 적절하다고 설명하는 부분이 있다.
________________________________________
12. 비견격 + 정관
BG-033
비견격이 정관을 만나면 기본적으로 좋은 방향이 될 수 있다.
다음을 확인한다.
•	정관 RootState
•	상관의 공격 여부
•	관살혼잡 여부
•	정관 합거 여부
•	일간이 정관을 감당 가능한가
정관 존재만으로 성격을 확정하지 않는다.
________________________________________
13. 비견격 + 재성
BG-034
비견격에서 재성을 사용할 때는 다음을 확인한다.
1.	재성 Root가 충분한가
2.	재성이 비견에게 직접 공격받는가
3.	식상이 비견과 재성 사이를 통관하는가
4.	칠살이 함께 존재한다면 재성이 그 칠살을 실제로 살리는가
중요
재성 + 칠살 존재
자동 불리
가 아니다.
재성이 칠살을 생하는 관계가 실제로 있어도, 그 칠살이 현재 구조에서 어떤 역할인지 먼저 판단한다.
특히 비견격에서 칠살이 이미 병으로 작동하거나 강하게 살아나고 있는데 재성이 그 칠살을 더 키우면 불리할 수 있다.
전문가 비견격 사례에서도 재성이 들어오면서:
상관생재
→ 재생살
구조가 만들어지고, 동시에 칠살국까지 강해지는 것을 문제로 판단한 사례가 있다.
따라서 BG-034에서는:
check 財生殺
을 유지하되 조건부 구조 판단으로 사용한다.
________________________________________
14. 비견격 + 재생살 판정
BG-035
다음과 같은 경우 재생살을 불리한 경로로 본다.
七殺 already harmful/active
+
財 supports 七殺
→ 칠살 문제 강화.
반대로:
•	칠살이 약하고
•	현재 구조에서 제어 가능한 상태이며
•	다른 유정한 구조가 존재
한다면 재생살 사실만으로 자동 파격하지 않는다.
금지
比肩格 + 財生殺 = 자동 흉
규칙은 사용하지 않는다.
________________________________________
15. 비견격에서 식상 통관
BG-036
중요한 구조:
比肩 → 食傷 → 財
비견이 재성을 직접 공격하지 않고 식상으로 기운을 흘려 재성을 생하면:
•	비견의 과도한 자기세력 완화
•	식상 활용
•	재성 보호·생조
가 가능하다.
따라서 식상은 비견격에서 중요한 보조 통관 기능을 할 수 있다.
________________________________________
16. 비견격 + 인성
BG-037
인성은 일간·비견을 강화한다.
따라서 이미 비견이 강한 경우 인성 추가가 항상 좋은 것은 아니다.
그러나 인성이:
•	정관 보호
•	필요한 학습·문서 기능
•	특정 병 해소
를 수행하면 유리할 수 있다.
________________________________________
17. 겁재격의 기본 성격
BG-040
겁재는 비견보다 재성 분탈성이 강하다.
겁재격에서는 먼저 다음을 본다.
•	재성이 겁재와 직접 맞붙는가
•	관성이 겁재를 제어하는가
•	식상이 통관하는가
•	인성이 겁재를 더 키우는가
전문가 사례에서도 겁재 옆 인성이 겁재를 생하고, 겁재가 재성을 직접 보는 것을 명확한 문제로 해석한다.
________________________________________
18. 겁재격 + 재성 직접 대면
BG-041
劫財 → 財
직접 공격 구조는 겁재격의 핵심 병 후보다.
특히:
•	식상 통관 없음
•	관성 제어 없음
•	인성이 겁재를 생함
이면 재성 손상이 커질 수 있다.
________________________________________
19. 겁재격 + 식상
BG-042
식상은 겁재와 재성 사이에서 중요한 보조 기능을 한다.
劫財 → 食傷 → 財
가 성립하면:
•	겁재 설기
•	재성 생조
•	직접 분탈 완화
가 가능하다.
FILUNE APPROVED
식상은 겁재격에서 주용신보다 보조 기능을 우선한다.
________________________________________
20. 겁재격 + 관성
BG-043
관성은 겁재를 제어할 수 있으므로 중요하다.
정관
겁재를 질서 있게 제어.
칠살
강한 겁재를 더 직접적으로 제어할 수 있다.
FILUNE에서는 겁재격에서 칠살을 주용신 후보로 사용할 수 있다.
________________________________________
21. 겁재격에서 칠살
BG-044 FILUNE APPROVED
비견격과 달리 겁재격에서는 칠살 사용을 허용한다.
이유는 겁재의 강한:
•	재성 분탈
•	자기세력
을 칠살이 제어할 수 있기 때문이다.
단:
겁재격 = 칠살 무조건 최고
로 고정하지 않는다.
다음을 본다.
•	겁재 기세
•	칠살 RootState
•	일간 감당력
•	재성 상태
•	식신의 제살 정도
•	관살혼잡
________________________________________
22. 겁재격의 관성 내부 우선순위
BG-045
FILUNE에서 확정된 것은:
•	칠살 사용 가능
•	정관 사용 가능
•	식상 보조
까지다.
정관·칠살·재성 사이의 절대 공통 순위는 모든 겁재격에 대해 고정하지 않는다.
실제 구조에서 어떤 기능이 겁재를 가장 적절히 제어하고 재성을 보호하는지 본다.
________________________________________
23. 겁재격 + 인성
BG-046
인성은 겁재를 생하므로 겁재가 이미 강한 경우 문제가 될 수 있다.
예:
印 → 劫財 → 剋財
가 성립하면 재성 손상이 커질 수 있다.
하지만 인성이:
•	칠살 인화
•	일간 Capacity 보완
•	다른 구조적 병 해소
를 수행하면 자동 흉으로 처리하지 않는다.
________________________________________
24. 겁재격 + 재성
BG-047
재성을 사용할 수 있지만 반드시 보호 구조를 본다.
좋은 후보:
劫財 → 食傷 → 財
또는:
官殺 controls 劫財
→ 財 보호.
불리 후보:
印 → 劫財 → 財 damage
________________________________________
25. 양인격의 기본 성격
BG-050
양인은 겁재보다:
•	자기세력
•	재성 분탈
이 더 강한 특수 구조로 본다.
전문가 자료는 양인이 재성을 직접 보면 재성 분탈이 매우 커질 수 있다고 반복해서 설명한다.
따라서 양인격은 제어 가능한가가 핵심이다.
________________________________________
26. 양인격에서 칠살을 가장 먼저 본다
BG-051
전문가 자료는 월지가 양인일 때 칠살을 가장 귀하게 사용한다고 명확히 설명한다.
양인은 이미 일간이 매우 강한 상태이므로 정관보다 더 강한 칠살로 제어하는 것이 유리할 수 있다고 본다.
________________________________________
27. 양인격 FILUNE 용신 우선
BG-052 FILUNE APPROVED
FILUNE v1에서는 양인격을:
칠살 > 정관 > 재성
순으로 우선 검토한다.
식상은 기본적으로 보조 기능이다.
주의
전문가 자료 일부에서는 양인격에서:
칠살 → 정관 → 식신
을 귀하게 보는 설명이 존재한다.
FILUNE v1에서는 사용자 승인 기준으로:
•	칠살 주용신
•	정관 차순위
•	재성 조건부 사용
•	식상 보조
로 구현한다.
________________________________________
28. 양인용살
BG-053
대표 구조:
七殺 → 制 羊刃
좋은 조건:
•	칠살 실제 작동 가능
•	칠살 Root 존재
•	합거되지 않음
•	식상이 불필요하게 칠살을 제거하지 않음
•	일간이 칠살을 감당 가능
________________________________________
29. 양인격에서 식신이 칠살을 제거하는 경우
BG-054
일반 칠살격에서는 식신제살이 귀할 수 있다.
그러나 양인격에서는 칠살 자체가 양인을 제어하는 귀한 기능일 수 있다.
따라서:
食神 → 制 七殺
이 항상 좋은 것은 아니다.
전문가 자료에서도 양인격에서 가장 귀한 칠살을 식신이 극하면 오히려 귀를 손상시키는 것으로 설명한다.
________________________________________
30. 양인격에서 식신이 필요한 경우
BG-055
식상이 항상 불리한 것은 아니다.
격국론에서는:
•	칠살이 지나치게 강함
•	관살혼잡
•	관살의 태과를 덜어야 함
등의 경우 식상이 유용할 수 있다고 설명한다.
따라서 식상은 양인격에서:
auxiliary regulator
로 사용한다.
________________________________________
31. 양인격 + 정관
BG-056
정관은 칠살 다음의 중요한 제어 수단이다.
정관은 양인의:
•	과도한 자기세력
•	재성 분탈
•	경쟁성
을 사회적 질서로 연결할 수 있다.
다음을 확인한다.
•	정관 Root
•	식상의 공격
•	관살혼잡
________________________________________
32. 양인격 + 재성
BG-057
양인은 재성 분탈성이 강하므로 재성만 단독으로 들어오는 구조는 위험할 수 있다.
재성을 사용할 때는:
•	관살이 양인을 제어하는가
•	식상이 통관하는가
•	재성 Root가 충분한가
를 본다.

67. FILUNE 비겁계 특수격의 최종 원칙
비견격·겁재격·양인격을 판정할 때 가장 먼저 묻는 것은:
“비겁이 많으니 나쁜가?”
가 아니다.
다음 순서로 본다.
월령이 비견·겁재·양인 중 무엇인가
→ 현재 자기세력과 일간 Root가 얼마나 강한가
→ 그 강한 힘을 제어하거나 흘려보낼 관성·식상이 있는가
→ 재성이 있다면 분탈되는가 보호되는가
→ 비견격에서 칠살이 존재한다면 재성이 그 칠살을 실제로 문제될 정도로 살리는가
→ 겁재격·양인격에서는 어떤 관살이 자기세력을 제어하는가
→ Formation으로 비겁 세력이 더 강해졌다면 일간 감당력 증가와 재성 분탈 중 무엇이 더 중요한가
→ 인성이 비겁을 과도하게 키우는가 아니면 필요한 구조를 보호하는가
→ 그 결과 원래 격의 기능이 현실적인 성과로 연결되는가
를 판단한다.
따라서 비견·겁재·양인은 같은 비겁 계열이지만 관살을 사용하는 방식과 재성을 보호하는 방식이 서로 다르므로 반드시 별도 격으로 판정한다.
