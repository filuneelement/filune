# P4 Health Publication Contract

이번 발행 계약 개정은 B rev38 W-30의 고정 문형을 H2/H3의 조건에서 좁게 확장한다. 내부 CH-7, B W-31~35, D Q10의 안전 점검, A I-16의 전통 대응 범위는 적용한다. 원천 판본의 문구는 보존한다. 고객 렌더링은 후속 단계다. [B rev38](../../source/authority/B_rev38.md) · [D rev155](../../source/authority/D_rev155.md) · [A rev182](../../source/authority/A_rev182.md) · [⑲-A 원자료](../../source/health/FILUNE-19A-premium-health-evidence.md) · [Master 14](14-outcome-semantic-spec.md#health-source-contract)

| 단계 | 필요한 근거 | 변경 전 | 변경 후 고객 표현 |
| --- | --- | --- | --- |
| H1 전통 대응 | Canonical과 승인된 대응 Fact. 일간별 승인 범위 적용 | 고정 틀로 전통 대응 소개 | “전통 명리에서는 ○○ 영역과 연결해 봅니다.” H1만으로 부담·약함·주의 시기를 쓰지 않는다. |
| H2 구조적 부담 | structural_health_attention에 연결된 유효 adverse 경로, body_area_burden의 확인된 피해 대상, 승인 부위와 직접 원자료 또는 승인 연결. 확정된 operating·unfavorable 및 대상 ID 일치 필요 | 구조 부담은 내부 의미. 고객은 전통 대응 및 고정 주의 틀 | “전통 명리에서 이 명식의 ○○ 계통은 상대적으로 부담을 받기 쉬운 영역으로 읽힙니다.” 원국의 확정 조건에서는 “평소 더 신경 써서 볼 부위”도 가능. “상대적으로 약해지기 쉬운”은 신체 기능 약화로 읽힐 수 있어 “부담을 받기 쉬운”으로 표현한다. |
| H3 시기 활성 | 같은 Health 경로를 따로 평가한 국소 활성, 정확한 구간, 연결된 health_attention_period 및 부모 범위. 명명할 부위에는 H2 대상 근거 필요 | 확인된 시기에 해당 부위를 살피라는 고정 틀 | “특히 ○○ 시기에는 이쪽을 평소보다 조심해서 보는 편이 좋습니다.” “무리하지 않는 편”은 W-32와 별도 부담 근거가 허용하는 일정·책임의 양에만 사용한다. 부위별 행동 처방은 금지한다. |

H2/H3 문장에는 같은 문단 또는 카드 안에 전통 해석 맥락을 둔다. ‘상대적으로’는 명식에서 다른 근거와 구분해 살필 영역을 뜻한다. 비교 집단, 장기 기능 저하 또는 의학적 취약성의 의미는 허용하지 않는다. 조건부·감쇠·방향 후보·대상 미확정 경로에는 확정된 부위 부담 문구를 쓰지 않는다. 근거가 허용하면 조건을 유지한 채 부위 없이 리듬 수준만 표현한다. 정지·만료 경로에서 현재 주의를 생성하지 않는다. 미래는 해당 구간이 따로 평가된 경우만 허용한다.

질병·증상·진단·발병·수술·사망/수명·치료법·약·검사 시기 및 지시, 회복 전망, 의료 위험 점수, 식이·운동·조후 기반 처방은 제외한다. Certainty는 해당 전통 해석의 근거 강도를 뜻한다.

## 공개 QA

| 입력 | 기대 |
| --- | --- |
| 승인 대응만 있는 원국의 土 | H1 소개. 소화기 부담은 생성하지 않는다. |
| 유효 구조 경로, 실제 승인 대상과 원국 body_area_burden | H2 원국 주의. 시기 추정 금지. |
| 대상 연결 누락 또는 감쇠 | H2 부위 문구 제외. 지원되는 조건부 일반 표현만 검토. |
| 상위 세운 근거만 있고 월의 국소 활성 부재 | 해당 월 H3 보류. 세운 자체는 원래 범위에서 유지. |
| 별도 평가된 월 활성, 같은 대상, 정확한 절입 구간 및 불리한 작동 | H3 구간·부위 표현. 동일 Fact를 CH-7·CR-04/08/09에 참조. |
| 조건부 월, 정지 또는 만료 | 조건부 월은 부위 없이 리듬만. 정지·만료는 현재 주의 없음. |
| 일간 대응 밖의 사례 전용 부위 | 추가 승인 전 발행 보류. |

04는 현재 활성, 08은 경계 양쪽을 평가한 장기 전환, 09는 해당 연·절기월의 독립 활성에 사용한다. 무료는 기존 상품 승인과 충분한 원국 근거가 있는 보충 카드 후보이며 운의 시기는 제공하지 않는다.
