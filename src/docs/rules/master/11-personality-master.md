FILUNE v1 성격 해석 마스터 규칙 v0.1
0. 목적
이 문서는 FILUNE에서 사주의 성격·행동성향·사고방식·대인관계 방식을 해석하기 위한 기준을 정의한다.
성격 해석은 격국·성패·운세 판정과 별개의 해석층이다.
Structural Engine
≠
Personality Engine
두 엔진은 동일한 CanonicalChart를 사용하지만 목적이 다르다.
________________________________________
1. 성격 해석의 기본 구조
FILUNE 성격 해석은 다음 순서로 구성한다.
1. 일간 기본 기질
2. 원국 십성 성향
3. 천간/지지 위치에 따른 발현 차이
4. 월지의 타고난 본성
5. 일지·시지의 판단기제
6. 일주 성격 보정
7. 구조적 역할에 따른 발현 보정
8. 음양 편중 등 전체 성향 보정
________________________________________
2. 일간은 가장 기본적인 사고방식
일간은 성격의 출발점으로 사용한다.
예:
甲
→ 전진
→ 시작
→ 성장
→ 곧게 나아가려는 성향

乙
→ 유연성
→ 적응
→ 지속성

丙
→ 표출
→ 밝음
→ 외향적 발산

丁
→ 섬세한 표현
→ 내부 감정
→ 선택적인 발산
등이다.
단:
일간 하나 = 전체 성격
으로 사용하지 않는다.

5. 십성을 길신·흉신으로 성격 판단하지 않는다
자료에는 전통적인 길신·흉신 구분도 포함되어 있으나 FILUNE Personality Engine에서는 이를 성격의 좋고 나쁨으로 사용하지 않는다.
금지:
正官 = 좋은 성격
傷官 = 나쁜 성격
劫財 = 나쁜 성격
각 십성에는:
productiveExpression
excessiveExpression
이 모두 존재한다.

7. 단순 개수로 과다·부족을 정하지 않는다
다만 다음은 금지한다.

십성 0개 = 부족
FILUNE은 기존 구조 엔진의:
•	RootState
•	투출
•	Formation
•	월령
•	실제 작동 상태
를 이용해 effective prominence를 판단한다.
숫자 개수만으로 성격 강도를 결정하지 않는다.

8. 천간 = 드러나는 성격
십성(1) 자료의 성격 분석법을 채택한다.
천간의 십성은 주로:
외부에서 빠르게 보이는 성격
사회생활에서의 표현
타인이 처음 인식하는 모습
말과 행동으로 직접 표현되는 태도
로 해석한다.
________________________________________
9. 지지 = 내재된 성격
지지의 십성은 주로:
내면의 판단기제
본능적 성향
가까운 사람에게 드러나는 모습
오랫동안 관계했을 때 보이는 성격
으로 해석한다.
자료에서도 천간을 사회적으로 빨리 드러나는 성격, 지지를 숨겨진·내재된 판단기제로 구분한다.
________________________________________
10. 동일 십성이라도 천간과 지지는 다르게 표현
예:

11. 월지 = 타고난 본성

월지 = 전체 성격
은 아니다.

4. 일간 기본 기질
