FILUNE v1 지지 작용 마스터 규칙 v0.2
0. 문서의 지위
이 문서는 FILUNE v1 지지 판정 엔진의 실행 기준이다.
Codex는 이 문서에 없는 지지 작용 규칙을 구현 편의를 위해 임의로 추가하지 않는다.
지지 엔진의 목적은 단순히:
•	합이 있는가
•	충이 있는가
•	삼합인가
를 찾는 것이 아니다.
최종 목적은 다음 흐름을 판정하는 것이다.
지지 관계
→ 지지 세력 및 기능 변화
→ 반합·삼합·방합 Formation
→ 통근·RootState 변화
→ 일간 및 다른 천간의 기능 변화
→ 용신·상신·병·구응 변화
→ 격국 구조 및 성패 변화
→ 궁위·현실 해석
________________________________________
1. 천간과 지지는 직접 작용층을 분리한다
B-001
기본 직접 관계는:
•	천간 ↔ 천간
•	지지 ↔ 지지
로 본다.
지지가 천간을 직접 극한다고 처리하지 않는다.
천간이 지지를 직접 극한다고 처리하지도 않는다.
지지는 다음 경로를 통해 천간에 영향을 준다.
•	통근
•	12운성상 유무력
•	RootState
•	반합국
•	완전 삼합국
•	완전 방합국
•	충에 의한 뿌리 약화
•	지지 오행 편중
따라서:
Branch State
→ RootState
→ Stem Functional State
순서로 연결한다.
________________________________________
2. 지지는 월령을 중심으로 격을 본다
B-002
지지 해석에서는 월령의 대표 십신을 격의 중심으로 한다.
예:
•	월지 정관 → 지지 정관격
•	월지 재성 → 지지 재격
•	월지 인성 → 지지 인수격
•	월지 식신 → 지지 식신격
•	월지 칠살 → 지지 칠살격
•	월지 비견 → 지지 비견격
•	월지 겁재 → 지지 겁재격
월령 지장간 전체는 별도 사실로 보존한다.
________________________________________
3. 관계 자체에는 길흉이 없다
B-003
다음 규칙은 금지한다.
•	합 = 무조건 길
•	충 = 무조건 흉
•	형 = 무조건 흉
•	삼합 = 무조건 길
•	방합 = 무조건 길
항상 다음을 확인한다.
1.	어떤 지지가 관계에 참여했는가
2.	각 지지가 어떤 십신인가
3.	월령 격과 어떤 관계인가
4.	용신·상신·병·구응인가
5.	천간의 뿌리인가
6.	Formation으로 어떤 오행·십신이 강해지는가
7.	어느 궁위인가
8.	그 결과 격 구조가 어떻게 변하는가
________________________________________
4. 모든 지지 관계는 동시에 존재할 수 있다
B-004
하나의 지지가 같은 scope에서 동시에:
•	육합
•	삼합 관계
•	반합국
•	방합
•	충
•	형
•	파
•	해
등에 참여할 수 있다.
관계 하나를 발견했다고 다른 관계를 삭제하지 않는다.
전문가 자료 역시 지지는 복합적인 기운이므로 어떤 글자가 합을 하면서도 다른 글자와 다시 관계를 가질 수 있다고 설명한다.
________________________________________
5. RelationFact와 EffectFact를 분리한다
B-005
예:
卯와 酉가 있으면:
ClashRelation = true
다.
그러나 卯가 다른 글자와 합 또는 Formation을 이루고 있다면 실제 충 효과는 약하게 나타날 수 있다.
따라서:
RelationFact
무슨 관계가 존재하는가.
EffectFact
그 관계가 현재 얼마나 실제로 작동하는가.
를 분리한다.
________________________________________
6. 합과 충은 동시에 존재한다
B-006
합이 있다고 충 Relation을 삭제하지 않는다.
충이 있다고 합 Relation을 삭제하지도 않는다.
동시에:
HarmonyRelation = active
ClashRelation = active
가 가능하다.
________________________________________
7. 합이 존재하는 상태의 충
B-007
이미 합 관계가 존재하는 지지가 충을 받으면 충은 발생한다.
다만 실제 충 작용은 약해질 수 있다.
예:
clash.exists = true
clash.effect = mitigated
중요
충의 작용이 약해졌다고 충이 없어진 것은 아니다.
또한 충이 반드시 해로운 것도 아니다.
충이:
•	병을 약화
•	과도한 흉신 세력을 흔듦
•	막힌 구조를 변화시킴
등으로 작동하면 구조적으로 유리할 수도 있다.
________________________________________
8. 합의 자동 무력화 규칙은 사용하지 않는다
B-008
다른 합이나 Formation이 생겼다는 이유로 기존 합을 자동 삭제하거나 무효화하지 않는다.
유효한 합 관계는 모두 동시에 보존한다.
운에서 동일 방향의 합 요소가 추가되면 합의 작용이 강화될 수 있다.

10. 육합은 천간 합거가 아니다
B-011
천간 합은 합거가 되어 기능 정지가 가능하다.
지지 육합은 합거로 처리하지 않는다.
전문가 자료에서는 지지 합은 기능이 완전히 사라지는 것이 아니며 辰酉合도 기능 상실보다는 약화로 봐야 한다고 설명한다.
따라서:
六合 → stopped
는 금지한다.
________________________________________
11. 육합은 특정 오행국을 만들지 않는다
B-012
FILUNE에서는 육합을 근거로:
•	木 강화
•	火 강화
•	金 강화
•	水 강화
를 자동 발생시키지 않는다.
육합의 기본 기능은:
•	묶임
•	결속
•	독립 기능 약화
•	관계 조정
이다.

B-013

•	불리한 지지의 독립 작용 억제
불리 가능
•	중요한 길신의 기능 약화
•	용신의 독립 기능 감소
•	필요한 지지 작용이 묶임
육합 자체에는 고정 길흉이 없다.

17. 반합국의 효과
B-024
반합국이 형성되면:
•	해당 오행 지지 세력 강화
•	해당 십신 기능 강화
•	해당 오행 천간의 통근 기반 강화 가능
•	해당 오행 천간의 RootState 강화 가능
을 인정한다.
질적 강도는:
완전 삼합국 > 반합국
으로 본다.
임의 숫자 비율은 사용하지 않는다.

18. 완전 삼합국
B-025
세 구성원이 모두 존재하면 완전한 삼합국으로 인정한다.
효과
•	해당 오행 지지 세력 강하게 강화
•	해당 십신 기능 강화
•	해당 오행 천간의 통근 기반 강화
•	해당 오행 천간의 RootState 강화
•	용신·상신·병·구응 기능 변화
•	격국 구조 및 성패 변화 가능
________________________________________
19. 삼합국은 실제 격 구조를 바꿀 수 있다
B-026
예:
미월 비견격에서 卯未가 칠살 반합국을 이루고,
운에서 亥까지 들어오면:
亥卯未
완전 木局으로 칠살 세력이 더 강해질 수 있다.
전문가 자료에서도 이 과정을 실제로 칠살 반합국 → 완전 칠살국 강화로 해석한다.
따라서:
Formation
→ TenGod Force Change
→ Structure Reassessment
를 수행한다.

20. Formation이 문제를 해결하는 경우
B-027
Formation은 흉신을 강화하는 것뿐 아니라 문제 해결에도 사용될 수 있다.
전문가 사례에서는 亥卯未가 식신국을 이루어 식신 자체가 안정적으로 강해지고 칠살을 제어하는 구조를 매우 좋게 평가한다.
즉:
FoodGod Formation
→ SevenKilling Control 강화
가 가능하다.
________________________________________
21. 삼합·반합과 천간 RootState
B-028
Formation은 지지 내부 효과에 그치지 않는다.
예:
木 반합국 또는 木 완전 삼합국이 만들어지면 甲·乙 천간이 해당 지지를 뿌리로 사용할 수 있을 때:
RootState = strengthened
를 검토한다.
________________________________________
22. 일간의 뿌리도 동일하게 강화된다
B-029 신규 보강
반합·삼합·방합이 형성한 오행이 일간과 같은 오행이거나 일간의 실질적인 뿌리가 되는 오행이라면:
Formation은 일간의 RootState 역시 강화할 수 있다.
즉:
FormationElement == DayMasterRootElement
이면:
DayMasterRootState = strengthened
후보가 된다.
________________________________________
23. 신강하다고 일간 뿌리 강화가 자동 불리한 것은 아니다
B-030 중요
다음 단순 규칙은 금지한다.
DayMaster already strong
→ more root = bad
신강·신약은 그 자체가 길흉의 최종 기준이 아니다.
핵심은:
현재 격 구조에서 일간이 무엇을 감당해야 하는가
이다.
________________________________________
24. 관성·칠살 구조에서 일간 Root 강화
B-031
정관·칠살은 일간을 극하는 기운이다.
따라서 다음 구조에서는 일간이 충분한 기세를 갖는 것이 중요하다.
•	정관격
•	칠살격
•	천간에 강한 정관 존재
•	천간에 강한 칠살 존재
•	관살혼잡
•	재생관
•	재생살
특히 칠살을 쓰는 구조에서는 일간이 약하면 칠살을 감당하기 어렵다.
전문가 자료도 직접:
칠살을 쓰는 경우는 일간의 뿌리가 왕한 것이 좋음
이라고 설명한다.
또 칠살이 강한 상황에서는 비겁이라도 있어 일간이 버틸 수 있게 하는 것이 필요할 수 있다고 설명한다.
________________________________________
25. 칠살격에서 Formation으로 일간이 강해지는 경우
B-032
예:
칠살격 또는 천간 칠살이 강하게 작동하는 상황에서:
반합·삼합·방합이 일간의 뿌리 오행을 형성하면:
DayMaster Root strengthened
→ SevenKilling bearing capacity 증가
로 볼 수 있다.
이 경우 원래 일간이 이미 신강한 편이라고 하더라도 추가 Root 강화가 구조적으로 도움이 될 수 있다.
________________________________________
26. 격국론 근거 — 칠살격은 일간을 돕는 운을 반길 수 있다
격국론에서도 칠살격에 관살혼잡이 있는 경우:
일간이 가벼우면 일간을 돕는 운을 반긴다.
고 설명하며, 칠살격을 다스리려면 일간의 기세가 필요하다고 설명한다.
따라서:
칠살격 + 일간 Root Formation
은 단순히 비겁 증가라고 판단하지 않고 칠살 감당력 증가 효과를 별도로 평가해야 한다.
________________________________________
27. 천간 칠살이 있는 경우도 동일하다
B-033
월령이 칠살격이 아니더라도 천간에 칠살이 강하게 존재하고 실제로 일간을 공격한다면:
일간의 뿌리를 강화하는 반합·삼합·방합은:
•	일간 생존력
•	칠살 감당력
•	관살 압박에 대한 저항력
을 높일 수 있다.
즉:
SevenKillingPressure
+
DayMasterRootFormation
→ 구조적 완충 효과 가능
으로 판단한다.
________________________________________
28. 정관 구조에서도 일간 기반을 확인한다
B-034
정관은 길신이지만 일간을 극하는 기운이라는 본질은 동일하다.
따라서 정관이 강하고 일간이 지나치게 약하면 정관의 귀함을 충분히 감당하기 어렵다.
이 경우 일간의 뿌리를 강화하는 Formation은 유리할 수 있다.
다만 칠살보다 정관은 순용하는 길신이므로 무조건 일간 강화가 최우선이라고 하지는 않는다.
다음을 함께 본다.
•	정관 기세
•	일간 기세
•	재성의 생관
•	인성의 보호
•	관살혼잡 여부
•	일간 RootState
________________________________________
29. 재격에서도 일간 뿌리가 도움이 될 수 있다
B-035
재성이 왕한 경우 일간이 재성을 감당할 수 있어야 한다.
전문가 자료에서도 재성이 왕한 사주에서:
일간의 뿌리가 있어야 재성을 쓸 수 있다
는 식으로 판단한다.
따라서 재격에서도 반합·삼합·방합이 일간의 뿌리를 강화하면:
wealth-bearing capacity
를 높일 수 있다.
즉 일간 Root 강화는 관살격에만 국한하지 않는다.
________________________________________
30. 이미 신강해도 도움이 될 수 있는 경우
B-036
다음과 같은 경우에는 일간이 이미 신강하더라도 추가 Root 강화가 도움이 될 수 있다.
•	강한 칠살을 감당해야 함
•	관살혼잡을 버텨야 함
•	강한 재성을 운용해야 함
•	일간이 여러 곳으로 설기·극을 당함
•	구조상 일간의 지속적인 버팀이 필요함
따라서:
strong DayMaster
+
additional root
를 자동 과다로 판단하지 않는다.
________________________________________
31. 반대로 일간 Root 강화가 과할 수 있는 경우
B-037
일간 강화가 항상 좋은 것은 아니다.
전문가 자료에는:
•	인성이 이미 매우 왕하고
•	일간의 뿌리도 왕하고
•	칠살의 뿌리까지 왕해지는 경우
귀하기 어려워질 수 있다고 설명하는 사례가 있다.
즉:
strong Resource
+
strong DayMaster
+
strong SevenKilling
처럼 이미 전체 구조가 과중한데 일간까지 더 왕해지는 경우는 균형을 해칠 수 있다.
따라서 일간 Root 강화는 반드시 현재 구조의 필요량을 기준으로 판단한다.
________________________________________
32. DayMasterCapacity를 별도 판정한다
B-038
Formation이 일간 뿌리를 강화했을 때 단순:

95. FILUNE 지지 엔진 최종 원칙
FILUNE은 지지를 다음 순서로 판단한다.
어떤 합·충·형이 동시에 존재하는가
→ 어떤 반합·삼합·방합이 실제로 성립했는가
→ 어떤 오행과 십신의 세력이 강화되었는가
→ 그 Formation이 어떤 천간의 뿌리를 강화했는가
→ 일간의 뿌리도 강화되었다면 현재 관성·칠살·재성 등을 감당하는 데 도움이 되는가
→ 아니면 이미 과한 일간·인성·비겁을 더 과하게 만드는가
→ 용신·상신·병·구응의 실제 기능이 어떻게 변했는가
→ 그 결과 격국 구조가 좋아졌는가 나빠졌는가
→ 동시에 어느 궁위에서 현실 변화가 나타나는가
따라서 신강·신약은 지지 Formation의 길흉을 결정하는 독립 규칙이 아니라, Formation으로 강화된 일간이 현재 격의 요구를 얼마나 잘 감당하게 되었는지를 판단하는 보조 축으로 사용한다.
