3. OP-L01 scope 처리
기존 ExecutionScopeContext 검증 및 candidate 선택을 재사용했다.
대운: 원국 + 선택 대운.
세운: 원국 + 선택 대운 + 선택 세운.
월운: 원국 + 선택 세운 + 선택 월운.
Producer 원본은 유지한다. 실행 관측 relation/coverage에는 별도 scope-bound ID를 부여하고 원본 relation ID·producer·evidence 계보를 보존한다.
월운에서 대운 entity를 직접 비교하거나 대운–월운 신규 합을 생성하지 않는다.
현재 contract에는 일진 scope가 없어 이번 API에서는 미지원이다. 임의 enum이나 일진 계산을 추가하지 않았다.

4. OP-T10 운끼리 합
현재 직접 비교 운끼리의 합을 먼저 처리한다.
성립한 두 entity는 weakened이며 stopped가 아니다.
그 두 entity는 원국과 새로 합하지 않는다.
약화는 질적 상태·문서 근거로만 기록한다. 약화된 상태를 참조할 수 있지만 생극 결과·점수·비율은 계산하지 않는다.
이전 ‘원국 합 우선’ 이력 규칙은 실행하지 않는다.

5. OP-T03/04/07/08
OP-T03: 운이 여러 원국 글자와 합할 수 있으면 년간 → 월간 → 시간 순서로 선택한다.
OP-T04: 일간을 일반 운세의 합거 상대에서 제외한다.
OP-T07: 원국–운 합이 성립하면 두 entity를 stopped로 생성한다.
OP-T08: 유효한 기존 원국 stopped 상태를 유지하고 새 합 상대에서 제외한다.
이번 상태의 active는 ‘이 slice에서 합에 의한 기능 제한이 성립하지 않음’이다. 전체 명리 기능·강도 평가가 아니다.

6. Carry 처리
원국에 발생한 stopped 변화만 원래 sourceStateRef, sourceStage, causedByApplicationRefs/ruleIds, validity.from/to, inheritedThrough와 함께 승계한다.
sourceStateRef가 요청의 sourceStateId에 해당한다.
새 하위 단계에서 같은 원국 변화를 새 합 결과로 재생성하지 않는다.
RuntimeState 기능 상태는 active/weakened/stopped이며, inherited는 originMode에 기록한다. restored는 생성하지 않는다.
운끼리 weakened 상태는 승계하지 않는다.
이전 운–원국 합으로 stopped가 된 운 글자는 필요할 때 원래 state ID·scope·원인·기간의 역사 참조로 유지하며, 새 inherited 운 상태를 만들지 않는다.
중복 source/provenance consume, change ID 바꿔 재소비, 기간·scope·원인 참조는 기존 validateContractBundle로 검사한다.
IR-01에 따라 월운에서 이전 세운–원국 처리 결과를 새 판단으로 다시 생성하지 않는다.

8. CS-005 기대값과 일치/불일치
구조 범위에서 일치:
- 己未 대운: 대운 己와 원국 년간 甲이 stopped.
- 입춘 이후 丁未 세운: 丁과 원국 시간 壬이 stopped.
- 2027.1: 丙午 세운 丙과 辛丑 월운 辛이 weakened.
- 2027.1: 원국 월간 丙은 active로 남으며, 월운 辛과 재합거되지 않음.
- 대운에서 발생한 원국 甲 stopped는 provenance를 보존해 승계.
C rev215 C-10-2의 2027.1 ‘상신 丙 유지’ 가운데 ‘원국 丙이 기능 정지되지 않음’만 비교했다.
丙의 상신 역할이나 천간 유리 우세/지지 공존 등의 최종 길흉은 판정·검증하지 않았다.
기대값은 테스트 assertion에서만 사용한다. 불일치 시 source expected, events, states, processing history, evidence가 assertion 메시지에 출력된다.

검사 입력에 관한 한계:
C의 역산 출생일과 戌시 범위 하한(19:30)을 합성 대표 시각으로 사용했다. 관측된 정확한 출생시각이라고 주장하지 않는다.
이 대표 입력의 실제 Canonical 원국이 C 원국과 일치함을 assertion으로 확인했다.
별도 Rule 단위 합성 fact 배열은 상대 순서·일간 제외·재사용 금지 검사 전용이다. 실제 만세력 계산 정답이나 CS 기대값 fixture로 채택하지 않았다.

지원 범위의 추가 한계:
- Carry 원인 기간이 하위 실행 기간 전체를 덮지 않으면 경계 분리가 필요하므로 거부한다. 임의 복원 상태를 생성하지 않는다.

- 일진 scope는 현재 contract 미지원이다.
