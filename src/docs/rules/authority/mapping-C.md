# 문서 C rev215 회귀검증 매핑

현행 고정값은 C-10. C-1~C-9는 입력·계산 증거 및 동결 이력이며 현행 판정으로 복사하지 않는다. 아래 기대값은 원문 전사이며 현재 엔진을 실행하거나 그 출력을 사용하지 않았다. CS-127 월운 상세는 25-7 rev16 5-4에 별도 출처를 둔다.

연결 규칙 수는 해당 사례 절 또는 CS 이름이 직접 나온 행에서 완전/축약 Rule ID가 명시된 고유 A inventory ID의 합집합이다. 일반 규칙 적용을 추론하지 않는다. 이력의 참조도 포함하므로 현행 실행 규칙 수가 아니다.
