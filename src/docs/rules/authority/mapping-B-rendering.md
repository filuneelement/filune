# B rev38 Renderer / Access 매핑

B는 명리 판정 엔진이 아니다. B-0 및 B-1-10에 따라 완료된 내부 판단을 고객 말로 옮긴다. JudgmentResult/Renderer 타입·입출력 schema는 원문에 정의되지 않았다. 아래 분류는 문서화용이며 새 Rule Registry 등록이 아니다.

W-01은 한국어의 친근하고 차분한 반말, W-19는 일본어 문장·호칭 금지다. 일본어 작성 기준으로 사용하지 않는다.

## Renderer 입력 확인 사항

W-05/W-06은 자연 작용으로 이유를 같은 문단/표 행에 설명하도록 요구한다. W-16은 rule ID·출처·등급을 고객 본문에서 숨긴다. W-07의 조건부를 확정으로 승격하지 않는다. W-80~99의 내부 판단 열은 소비하는 판정의 조건이며 B에서 재판정하는 로직이 아니다. 이력 표기와 현행 축별 표기 차이는 보존한다. 자유 문장 예시를 모든 명식의 고정 문장으로 복제하지 않는다.
