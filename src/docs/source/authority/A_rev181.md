OP 표시(㉔ 추가): 운영자가 실제 감명 방법으로 직접 확정하거나 승인한 기준이다. 판정에는 OP를 따르지만, 원전 학설(S2)이나 전문가 판단(S3)으로 표기하지 않는다. 합 해석의 현행 기준은 A-8(OP-1113)이고, A-5·A-6·A-7은 2026-11-12 기준본이다(A-8과 다르면 A-8을 따름). ㉔-6에서 운영 제안이던 U-O3~U-O6과 I-20~I-22의 운영 부분이 운영자 승인으로 OP(OP-T09~T11, OP-Z09, OP-R01~R03)가 되었다. 이것은 FILUNE의 운영자 승인 기준이고, 고전에서 모두 직접 확인된 보편 법칙으로 기록하지 않는다. 2026-11-13 운영자 최종 승인 규칙(OP-1113)은 A-8에 있고 다른 모든 절보다 우선한다(U-O7은 A-8-4 OP-T08 보완, U-O8은 OP-Z10·Z07로 흡수). 이전 확장 제안(U-O7·U-O8) 기록은 A-7-3에 따로 있다.
절대 원칙
1.	점수·확률·적중률을 만들지 않는다.
2.	죽음·질병을 예측하지 않는다. 투자 지시를 하지 않는다.
3.	없는 사건을 지어내지 않는다. 불리한 판단을 지우지 않는다.
4.	출처 층을 섞지 않는다: 〔원〕 원전 / 〔번〕 번역 / 〔판〕 전문가 판단 / 〔적〕 FILUNE 적용 / 〔규〕 운영 규칙 / 〔일〕 일주론 / 〔설〕 현대 해설.
5.	문헌 검증과 실제 적중 검증을 혼동하지 않는다. 이 문서의 어떤 규칙도 ‘적중이 확인되었다’는 뜻이 아니다.

A-1-3. 계산 검증 방법
•	서로 독립된 두 계산(예: 공개 만세력 라이브러리 + 천문 계산)과 공공 역법 자료를 대조한다. 같은 방식의 계산을 두 번 돌리는 것은 대조가 아니다(㉒에서 기존 값이 한 가지 천문 계산에만 의존해 3~5분 이르게 나온 사례).
•	원고의 나이·연도 기록(예: ‘34세부터 기미대운’)과 계산한 대운이 맞는지 확인한다.
•	확인하지 못한 값은 ‘미확인’으로 남긴다.
A-2. 해석 기준
각 규칙은 원전 / 전문가 사례 / FILUNE 적용 세 칸으로 근거를 나눠 적는다. 사례 칸의 CS 번호는 문서 C에 있는 사례이다. 사례는 그 규칙이 쓰인 예일 뿐, 사례의 결론을 다른 명식에 그대로 옮기지 않는다.

### ⑥ 병(病) 판정 실행 규칙

이 절은 A-8-2의 ⑥을 구체화한다. 병은 I-03의 글자 단위 역할로 기록하며, 작용은 그 글자에 병 역할을 귀속할 때 확인하는 손상 경로다. I-04-2의 예외와 통관·보호 조건, I-04a·I-04c의 성패 판단은 각 규칙을 따른다.

#### 1. 기본 정의

병(病)은 해당 명식에서 확정된 격국의 성립·유지 또는 그 격을 성립시키는 용신·상신의 기능을 실제로 손상시키는 글자 또는 작용이다.

병은 특정 오행·십성·글자 자체로 고정하지 않는다. 같은 오행·같은 십성이라도 자리, 작용 상대, 관계, 현재 기능 상태가 다르면 병 여부가 달라질 수 있다.

따라서 다음은 병의 확정 근거가 될 수 없다.

- 특정 오행이라는 사실만 있는 경우
- 특정 십성이라는 사실만 있는 경우
- 생·극·합·충 관계가 존재한다는 사실만 있는 경우
- 문헌 사례에서 같은 글자가 병으로 판정된 적이 있다는 사실만 있는 경우
- 격국의 용신 또는 상신과 반대되는 성질이라는 이유만 있는 경우

병은 반드시 해당 명식에서 실제 손상 경로가 확인되어야 한다.

#### 2. 판정 순서

병 판정은 다음 순서에 따른다. 1~5는 A-8-2의 ①~⑤에서 확인하고, 6~8은 ⑥에서 수행한다.

1. 격국 확정
2. 용신의 순용·역용 및 기능 확정
3. 상신 확정
4. 상신 및 관련 글자의 현재 기능 상태 확인
5. 보호해야 할 격국·용신·상신 기능 확정
6. 병 후보 조사
7. 실제 손상 경로 확인
8. 병 확정 또는 보류

선행 판단에 필요한 핵심 정보가 미확정이면 병 판정도 확정하지 않는다.

#### 3. 병 후보의 조사 단위

병 후보는 다음 단위로 식별한다.

- entity ID
- 천간 또는 지지
- 위치
- 원국·대운·세운·월운 등의 origin
- 십성 또는 구조상 역할
- 관계 상대
- 현재 기능 상태
- 근거와 출처

같은 글자가 여러 위치에 존재하면 각각 별도 후보로 조사한다. 한 entity가 여러 손상 경로를 가질 경우 entity를 중복 생성하지 않고 손상 경로를 복수로 기록한다.

지장간 단독 병 후보는 해당 지장간의 독립 작용을 인정하는 확정 규칙이 있는 경우에만 조사 대상으로 삼는다. 근거가 없으면 자동 후보로 확장하지 않는다. 운의 직접 비교 범위 및 상태 승계는 OP-L01·L02를 따른다.

#### 4. 보호 기능의 확정

병을 판단하기 전에 해당 격에서 보호해야 하는 기능을 먼저 명시한다.

- 격국 자체의 성립 기능
- 순용 또는 역용되는 용신의 기능
- 용신을 돕는 상신의 기능
- 확정된 통관·제어·화살·제살 등의 구조적 기능

보호 기능은 해당 격과 사례에 대한 현행 규칙에서 확인된 범위만 사용한다. 문서에 없는 기능을 새로 추정하여 병 판정 근거로 사용하지 않는다.

#### 5. 실제 손상 판정

병은 다음 세 단계를 모두 통과한 경우에만 확정할 수 있다.

**① 관계 존재**

후보에서 보호 기능에 이르는 경로에 생·극·합·충 또는 기타 현행 규칙에서 인정하는 관계가 실제로 존재해야 한다. 관계에 방향이 정의된 경우 그 방향을 확인한다.

**② 현재 작용 가능**

후보와 관계 참여자의 현재 기능 상태를 확인한다.

- `active`: 현재 작용 가능
- `weakened`: 작용은 남아 있으나 약화 상태
- `stopped`: 현재 작용 정지

구조적 역할의 존재와 현재 작용 상태를 구분한다. 합거로 손상을 입은 상대의 정지는 합거 효과에 해당한다. 이미 성립한 합거의 유효기간은 해당 운영 규칙에 따라 확인한다.

**③ 실제 손상**

관계가 존재하고 작용 가능하다는 사실만으로 병을 확정하지 않는다. 해당 관계가 현재의 격국·용신·상신 또는 보호 기능을 실제로 손상한다는 실행 규칙과 근거가 확인되어야 한다.

`존재 → 작용 → 실제 손상`의 세 단계를 구분한다.

#### 6. 식신격의 특별 규칙

I-04-2에 따라 식신격에서 인성이 실제로 식신 기능을 극하여 손상하는지 확인한다. 다음이 모두 확인된 경우 해당 글자를 병으로 확정할 수 있다.

1. 식신 기능이 확정되어 있을 것
2. 인성 후보가 식신 기능과 실제 극 관계에 있을 것
3. 후보가 현재 작용 가능한 상태일 것
4. 해당 극이 식신 기능의 실제 손상으로 이어질 것
5. 통관·제어 등으로 손상이 해소되었다면 그 상태를 함께 반영할 것

단순 인성 존재 또는 극 관계 존재만으로는 충분하지 않다. 통관·보호 이후 실제 손상이 남아 있으면 식신 기능의 유지와 병의 성립을 함께 기록할 수 있다.

#### 7. 칠살 역용 구조의 재성 관련 병

칠살을 화살 또는 제살하여 사용하는 구조에서는 재성이 칠살을 생한다는 사실만으로 병으로 판정하지 않는다.

재성 후보를 병으로 확정하려면 다음을 확인한다.

1. 해당 재성이 실제로 구조상 칠살을 생하는 관계에 있을 것
2. 그 관계가 현재 작용 가능한 상태일 것
3. 칠살에 대한 기존 화살·제살 기능을 고려한 뒤에도 손상이 남을 것
4. 그 손상에 해당 재성의 기여가 확인될 것
5. 천간과 지지 경로는 각각 독립적으로 입증할 것

재성이라는 사실이나 재→살의 생만 확인되고, 실제 보호 기능 손상 또는 통관·제어 이후 손상의 잔존 여부를 확인할 수 없으면 `deferred`로 처리한다.

#### 8. 재에 의해 강화된 잔존 칠살의 병

재를 순용하거나 재의 생을 받는 칠살을 제어하는 구조에서는 다음이 모두 확인된 경우 해당 칠살 entity를 병으로 확정할 수 있다.

1. 재→칠살의 유효한 생 관계가 존재할 것
2. 칠살을 제어하는 식신·상신 등의 기능이 확인될 것
3. 해당 제어를 거친 뒤에도 칠살의 작용이 남아 있을 것
4. 남은 칠살 작용이 보호 기능을 실제로 손상할 것
5. 손상의 귀속이 해당 칠살 entity에 연결될 것

칠살이라는 사실, 생 관계의 존재, 제어가 약해 보인다는 이유만으로는 충분하지 않다. 손상 대상 또는 잔존 손상이 확인되지 않으면 `deferred`로 처리한다.

#### 9. 합거·정지·약화 상태

**합거 또는 기능 정지**

병의 구조적 역할과 원국 기록은 유지하되 현재 작용은 `stopped`로 기록한다. 현재 정지된 병의 본래 작용에 따른 손상 경로는 해당 기간의 실제 판정에서 작동 경로로 사용하지 않는다. 해당 합거의 구조적 효과는 기존 합거 규칙을 적용한다.

**약화**

`weakened` 상태는 병의 존재를 자동 해소하지 않는다. 약화 이후에도 실제 손상이 남는지 별도로 판단한다. 수치 임계값이나 임의 가중치로 손상 여부를 결정하지 않는다.

**병 제거**

I-04a·I-04c에 따라 합거·제어가 실제 손상을 완화하는지 확인한다. 병의 현재 손상이 제거되었더라도 다른 병과 상신·용신·격국 자체의 손상을 별도로 확인한 뒤 전체 성패를 판단한다.

#### 10. 복수 병

하나의 명식에 둘 이상의 병이 동시에 존재할 수 있다. 천간 병과 지지 병은 별도로 확정할 수 있다. 복수 병이 있을 경우 각 병마다 다음을 독립 기록한다.

- entity ID
- 위치
- origin
- 손상 대상
- 손상 경로
- 현재 상태
- 근거
- Rule ID
- evidence
- provenance

한 병이 정지 또는 제거되더라도 다른 병의 작용을 자동 해소한 것으로 보지 않는다.

#### 11. 병 없음과 판정 보류의 구분

**병 없음**

조사 대상과 관계 범위가 충분히 확인되었고 가능한 손상 경로가 모두 배제된 경우에만 판정한다.

**deferred**

다음 중 하나라도 해당하면 병 없음으로 판정하지 않고 보류한다.

- 보호 기능 미확정
- 후보 관계 미확정
- 손상 효과 미확정
- 현재 기능 상태 미확정
- 조사 coverage 불완전
- 해당 구조의 일반 실행 규칙 부재
- 필요한 독립 근거 또는 provenance 부족

#### 12. 판정 상태

병 후보 상태는 `candidate`, `rejected`, `deferred`로 구분한다.

최종 병 판정은 `confirmed`, `rejected`, `deferred`로 구분한다.

전체 명식의 병 상태는 다음과 같다.

- `has-byeong`: confirmed 병이 하나 이상 존재
- `no-byeong`: 조사 범위가 완전하고 가능한 병이 모두 배제
- `deferred`: confirmed 병이 없고 조사 또는 규칙·근거가 불완전

확정 병과 보류 후보가 함께 있으면 `has-byeong`과 함께 후보의 보류 사유를 기록한다.

#### 13. 사례와 일반 규칙의 분리

회귀검증 사례의 병 기대값은 일반 실행 규칙의 입력으로 사용하지 않는다. 사례에서 특정 글자가 병으로 확정되어 있더라도 일반 실행 규칙이 없으면 evaluator는 그 글자를 `deferred`로 처리한다. 사례 기대값은 evaluator의 산출 결과를 사후 검증하는 용도로만 사용한다.

다음과 같은 일반화는 금지한다.

- 칠살격이면 재성은 모두 병이다.
- 정재격이면 재가 생한 칠살은 모두 병이다.
- 식신격이면 인성은 모두 병이다.
- 특정 사례에서 壬·子·辛·未·戌이 병이었으므로 다른 명식에서도 같은 글자를 병으로 본다.

병은 항상 해당 명식의 구조와 실제 손상 관계를 기준으로 판정한다.

### OP-P06. 천간 극의 기능 도달과 약화

OP-L01·OP-L02와 IR-01에 따라 해당 scope의 직접 비교 범위와
유효한 원국 변화의 승계를 먼저 확정한다. 현재 단계에서 새로 평가할
천간 쌍에 한해 적용하며, 승계된 원국 천간은 동일 entity로 식별한다.
일간은 다른 천간과 동일한 적용 조건으로 생극의 능동 source가 될 수
있다. OP-T04의 일간합 제외는 합에 적용한다.

같은 scope에서 존재와 방향이 확정된 stem-controls 관계에 대하여,
source와 target의 현재 작용 자격 및 target의 기능 귀속과 작동을
확인한다. 적용 순서에 따른 합거·정지·우선 관계를 확인하여 해당
작용을 배제하는 확정 근거가 없고 필수 근거가 평가 시점에 함께
유효하면, 그 극은 해당 기능에 도달한 것으로 판정하고 weaken을
기록한다. 기능별로 적용 여부를 확인하며, 하나의 관계가 동일
entity의 여러 기능에 도달하면 기능마다 독립적으로 기록한다.

source 또는 target이 stopped이면 현재 극 효과를 생성하지 않으며
구조 관계와 역할 이력을 보존한다. 특정 기능에만 적용되는 정지는
그 범위 안에서 차단한다. weakened는 자동 제외하지 않는다.
작용 자격이나 배제 여부가 미확정이면 효과의 확정을 보류한다.
거리만으로 도달을 배제하지 않으며 약화를 수치화하지 않는다.
극으로 산출하는 effectType은 weaken이다. stop에는 별도의 정지
규칙과 해당 적용 근거가 필요하다.

용신·상신은 검증된 원국 역할 이력을 참조할 수 있다. 현재 범위의
작동은 적용 중인 구조와 현행 상태에서 별도로 확인한다. 일반 십성은
현재 작동하는 해당 천간에 귀속된 검증된 십성 사실로 식별한다.
용신·상신의 약화는 같은 불리한 맥락에서 핵심 구조 역할이 없는
일반 십성의 약화보다 해석상 중요하게 평가한다. 약화 유형은 동일한
weaken으로 기록한다. 병·구응, 통관·보호 후 남는 손상 및 길흉은
해당 후속 규칙으로 판정한다. 명시적으로 작용 자체를 차단하는 규칙이
있으면 도달 단계에 반영한다. 사례 서술과 expected는 산출에 사용하지
않는다.
