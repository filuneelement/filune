B-0. 문서 사용법
이 문서는 LUNE이 고객에게 건네는 감정서(무료 풀이 + 유료 11장 + 개인 질문 답)를 쓸 때의 기준이에요. 명리 판단 자체는 이 문서에서 하지 않아요. 판단은 문서 A의 규칙으로 끝낸 뒤, 그 결과를 고객의 말로 옮기는 방법만 다뤄요.

B-0-4. 이 문서를 읽는 순서
1.	B-1의 공통 규칙을 먼저 읽어요. 모든 장에 똑같이 적용돼요.
2.	쓰려는 절·장의 기준(B-2~B-5)을 읽어요. 각 기준은 목적 / 내부 필요 정보 / 핵심 전달 / 이 장에서만 다룰 것 / 중복 방지 / 근거 부족 시 / 생활 상태를 모를 때 의 일곱 칸으로 되어 있어요.
3.	다 쓴 뒤 B-6의 중복 지도로 장 사이 겹침을 확인하고, 문서 D의 Q1~Q14로 검사해요.

목적	고객이 ‘나를 아는구나’ 하고 느낄 네 모습을 근거와 함께 보여 준다
내부 필요 정보	일간의 성질, 일지(가장 가까운 사람의 자리, A I-15), 상신의 기질, 감정·판단과 연결되는 원국 작용. 일주론은 보조(W-40~W-43)
핵심 전달	네 단락: 겉으로 보이는 모습 / 가까운 사람에게 드러나는 모습 / 판단하는 방식 / 감정을 다루는 방식. 단락마다 근거 글자 한 번
이 절에서만 다룰 것	네 모습의 요약
중복 방지	2장이 같은 영역을 7면으로 넓힌다. ③에서 쓴 비유·결론 문장은 2장에서 반복하지 않고, 2장은 상황·조건을 더한다(W-12)
근거 부족 시	근거 글자가 없는 성격(예: 유머, 취향)은 쓰지 않는다. 일주론에만 있는 성격은 원국과 맞을 때만
생활 상태 미상	‘가까운 사람’으로 쓰고 배우자·자녀를 전제하지 않는다(W-50·W-51). 배우자 자리의 해석 자체는 ‘가장 가까운 사람을 나타내는 자리’로 유지
F-④ 타고난 강점과 반복되는 과제
항목	기준
목적	강점 셋, 과제 셋을 한 표로 보여 주고 둘이 같은 뿌리에서 나온다는 걸 알려 준다
내부 필요 정보	상신(강점의 원천), 병(과제의 원천), 구응(과제를 막는 힘)
핵심 전달	2열 표(강점 / 과제) 3행 + 공통 뿌리 한 문단(강점은 어디서, 과제는 어디서 나오는가)
이 절에서만 다룰 것	강점·과제의 짝 구조 표
중복 방지	3장은 이 표의 각 칸을 ‘어떻게 작동하고 어떻게 쓰는가’로 넓힌다. 3장에서 표를 다시 싣지 않는다
근거 부족 시	과제는 반드시 병·혼잡·충 등 실제 구조에서 나와야 한다. 구조 없는 일반적 약점(‘완벽주의’ 등)으로 칸을 채우지 않는다
생활 상태 미상	‘혹시 ~생각해 본 적 있다면’ 같은 경험 확인 문장을 쓰지 않는다(W-15)
F-링크 여기서 더 들어가면
항목	기준
목적	유료가 무엇을 더 다루는지 알려 준다
핵심 전달	‘어떤 사람인가’ → ‘언제 무엇을 하면 좋은가’. 일·돈·관계·몸·10년 흐름·12개월을 이름만 나열

B-3. 유료 1~4장
CH-1 타고난 운명의 설계도
항목	기준
목적	무료에서 따로 보여 준 열쇠들이 서로 어떻게 이어져 하나의 구조가 되는지, 그리고 지금 그 구조가 어느 10년 위에 서 있는지 보여 준다
내부 필요 정보	격·상신·병·구응의 관계도(A I-01~I-04), 글자 사이의 거리와 닿음(A I-06), 원국 합충의 존재/강도/격국 영향(A I-09), 현재 대운과 시작 시기(A C-05~C-07)
핵심 전달	① 열쇠들의 연결(표 또는 흐름 문단) ② 떨어져 있거나 맞닿아 있는 글자가 만드는 차이 ③ 반가운 기운과 부담이 되는 기운(자연의 이름으로) ④ 지금 서 있는 10년의 성격 한 문단
이 장에서만 다룰 것	‘반가운 기운 / 부담이 되는 기운’의 정의. 9·10장의 판정은 모두 이 정의를 따른다
중복 방지	④은 지금 10년의 이름과 방향만. 자세한 풀이는 8-3. 성격 묘사는 2장으로
근거 부족 시	미확정 작용(예: 회합이 충을 푸는가, A U-A1)은 ‘주변과 부딪히는 자리가 있어’처럼 존재만 쓰고 힘의 크기는 단정하지 않는다. 교운이 1년 안쪽이면 두 10년을 함께 쓴다(A I-13)
생활 상태 미상	현재 10년의 힘이 닿는 영역을 ‘일·돈·가까운 사람’처럼 자리로 말하고, 직업·혼인 상태를 전제하지 않는다
{이름}	장 첫 문단에 한 번(전환점, W-60)
CH-2 나라는 사람의 본모습
항목	기준
목적	성격을 7면(생각하는 방식, 책임감, 표현, 감정, 결정, 사람을 대하는 방식, 혼자 있을 때와 사회 속)으로 구체화한다
내부 필요 정보	일간·상신·월령의 기질, 정·편 혼재가 만드는 내적 긴장(A I-11), 일지, 일주론 보조(W-40~W-43)
핵심 전달	각 면: 제목에 특징을 담고(예: ‘생각하는 방식 — ‘왜’를 끝까지 묻는 사람’), → 근거 글자 → 구체적 장면 → 그 특징의 대가
이 장에서만 다룰 것	결정·표현·혼자 있을 때의 모습 같은 세부
중복 방지	무료 ③의 네 모습과 같은 문장 금지. 감정·판단을 다시 다룰 때는 ‘언제, 누구 앞에서, 어떤 조건에서’를 더한다. 강점·과제로 판정하는 문장은 3장으로
근거 부족 시	7면 중 근거가 약한 면은 짧게 쓰고 다른 면과 합치지 않는다(구성 유지). 일반론으로 채우지 않는다
생활 상태 미상	‘사람을 대하는 방식’에서 ‘가장 가까운 사람에게 / 일로 만나는 사람에게 / 처음 만나는 사람에게’로 나누고, 배우자·직장 상사를 전제하지 않는다. 감정 항목에서 몸의 반응을 추정하지 않는다(W-34)
CH-3 타고난 강점과 넘어야 할 과제
항목	기준
목적	무료 ④의 강점·과제를 ‘어떤 힘인가 / 언제 나오는가 / 어떻게 쓰면 좋을까’로 풀고, 둘이 만나는 원칙을 낸다
내부 필요 정보	상신이 살아나는 조건과 상하는 조건(A I-04), 병이 움직이는 조건, 구응의 위치
핵심 전달	강점 3개(각각 무엇인가→근거→어떻게 쓰면 좋을까) + 과제 3개 + ‘강점과 과제가 만나는 곳’(하나의 원인에서 나온다는 것과 생활 원칙 목록)
이 장에서만 다룰 것	강점을 쓰는 법, 과제의 대응법
중복 방지	무료 ④ 표를 다시 싣지 않는다. 일·돈에 대한 적용은 4·5장으로 미루고, 3장에서는 삶 전반의 태도로만. 11-2의 ‘기억할 셋’과 생활 원칙이 같은 말이 되지 않도록 11장을 먼저 정해 두고 맞춘다
근거 부족 시	‘가장 많이 성장한 때는 아마’ 같은 과거 추측을 쓰지 않는다(문서 C CS-005 이력). 성장 시기는 8장의 구조 판단으로만
생활 상태 미상	‘가르치거나 조언하는 일에서’처럼 일의 종류로 말하고, ‘지금 맡고 있는 직책’을 전제하지 않는다
CH-4 일과 성공이 열리는 방향
항목	기준
목적	일의 방식과 조건을 보여 주고, 지금 10년·12개월에서 움직이기 좋은 때와 준비하기 좋은 때를 알려 준다
내부 필요 정보	관성·식상·인성의 위치와 상신과의 관계, 격의 성패, 현재 대운의 방향(A I-12), 내부 월별 표의 일 관련 판정(A I-14)
핵심 전달	4-1 잘 맞는 일의 방식 / 4-2 조직 안에서, 그리고 혼자서 / 4-3 성과가 잘 나는 조건과 어려워지는 조건 / 4-4 지금 시기에 맞는 방향 / 4-5 움직이기 좋은 때와 준비하기 좋은 때
이 장에서만 다룰 것	직업군·일의 형태(자문, 교육, 기술 등)의 제안. 조직/독립 비교
중복 방지	4-5는 12개월 중 ‘일’에 해당하는 달만 묶어 쓰고, 그 달의 전체 풀이는 10장으로. 같은 달의 판정은 10장·내부 표와 반드시 같아야 한다(W-13). 돈의 때는 5-4로
근거 부족 시	월의 판정이 ‘혼합’·‘조건부’이면 ‘움직이기 좋은 때’ 목록에 넣지 않고 ‘준비’ 또는 ‘조건을 보고’로 분류한다. 전문가 대운 판단을 월로 내린 것(S4) 하나만으로 ‘가장 좋은 때’를 쓰지 않는다(A U-N6)
생활 상태 미상	직장인·사업가·구직 중 어느 쪽이든 읽히도록 ‘조직 안에서 / 혼자서’를 모두 쓴다(W-53). 이직·퇴사를 권하거나 단정하지 않는다
{이름}	장 첫 문단에 한 번 가능(전환점)
B-4. 유료 5~8장
CH-5 돈이 들어오고 머무는 흐름
항목	기준
목적	돈의 성격(들어옴·머묾)과 문제가 생기는 조건을 구조로 보여 주고, 12개월 안의 계약·사업·지출·협업의 때를 정리한다
내부 필요 정보	재성의 위치·정편·통근, 재성과 병의 관계(예: 재가 살을 키우는 구조), 구응의 위치, 내부 월별 표의 돈 관련 판정
핵심 전달	5-1 돈이 들어오는 방식 / 5-2 돈이 머무는 방식 / 5-3 돈 때문에 문제가 생기는 조건(표: 조건 / 왜) / 5-4 계약·사업·지출·협업의 때(표: 시기 × 네 항목) / 5-5 재물 원칙 세 가지
이 장에서만 다룰 것	돈의 종류 구분, 계약·지출·협업 표
중복 방지	무료 ②의 ‘돈과 책임’ 특징을 반복하지 않고, 5장은 ‘어느 조건에서, 언제’를 더한다. 5-4 표의 월 판정은 10장·4-5와 같아야 한다. 가까운 사람과 돈이 얽히는 문제는 5-3에서 조건만, 관계 쪽 풀이는 6-3에서
근거 부족 시	투자 지시 금지(W-11). ‘큰 지출·계약은 한 달 뒤로’, ‘서명 전에 한 번 더’ 수준까지. 판정이 혼합인 달은 표에 ‘보통’ 또는 조건을 함께 적는다
생활 상태 미상	‘가정을 꾸리는 돈’ 대신 ‘생활을 꾸리는 돈’(W-52, 문서 C CS-005 이력). 사업체 보유·대출 여부를 전제하지 않는다
CH-6 사랑과 평생의 인연
항목	기준
목적	가장 가까운 사람의 자리와 인연의 성격, 갈등의 구조, 관계의 때, 부모·형제·아랫세대와의 인연을 읽는다
내부 필요 정보	일지(배우자 자리), 성별에 따른 배우자 성(여성: 관성, 남성: 재성), 육친 자리(A I-15), 일지와 다른 지지의 합충, 내부 월별 표의 관계 관련 판정. 관계의 때는 A I-22·OP-R03(인연·결혼 시기)으로 읽고, 일지와 운의 합은 시기 조건일 뿐 관계 개선의 근거가 아니다(W-87)
핵심 전달	6-1 가장 가까운 사람의 자리 / 6-2 인연으로 다가오는 사람 / 6-3 갈등이 생기는 이유 세 가지 / 6-4 관계에 변화가 생기는 때와 부담이 생기는 때(또는 구조에서 나온 ‘잘 맞는 사람’ + 때는 다른 장으로 안내) / 6-5 부모·형제·아랫세대와의 인연
이 장에서만 다룰 것	육친 자리 해석, 인연으로 다가오는 사람의 성격
중복 방지	무료 ③ ‘가까운 사람에게 드러나는 모습’과 같은 결론을 쓸 때는 6-1에서 근거(어느 자리에 무엇이 있는가)와 조건을 더한다. 6-4의 월 판정은 10장과 같아야 한다
근거 부족 시	육친에 해당하는 글자가 원국에 드러나 있지 않은 명식의 처리는 세 사례에서 다루지 않았다. 그 항목은 단정하지 않고 자리(기둥)로만 짧게 읽으며, 문서 D의 미확정 과제로 등록한다. 일주론의 배우자 단정 금지(W-42). 6-4에서 ‘가까워지는 때’는 시기 신호가 있고 그 달 내부 판정이 유리일 때만 쓴다. 판정이 혼합·부담이면 ‘변화가 생기기 쉬운 때’로 쓰고 결정을 서두르지 않게 한다(W-88). 궁합 기준은 쓰지 않는다(W-89)
생활 상태 미상	이 장이 W-50~W-56의 주요 적용 장이다. ‘가장 가까운 사람’, ‘아랫세대’, ‘~이 있다면’을 쓰고, 가족 면책 문구를 넣지 않는다. 부모·자녀에 대해 ‘네가 챙겨야’, ‘몫으로 넘어와’처럼 책임을 지우는 문장을 쓰지 않는다(문서 C CS-005 이력)
{이름}	장 첫 문단에 한 번 가능(전환점)
CH-7 몸과 건강의 흐름
항목	기준
목적	사주가 가리키는 몸의 영역과 ‘언제 더 살피는가’를 알려 주되, 병을 예측하지 않는다
내부 필요 정보	일간·상신의 오행과 전통 신체 대응(A I-16), 각 달에 실제로 눌리거나 흔들리는 글자(내부 월별 표), 현재 대운·올해·내년의 방향
핵심 전달	7-1 사주가 가리키는 몸의 영역(W-30 틀) / 7-2 왜 이 곳을 살피는지(구조 설명) / 7-3 지금의 큰 흐름과 올해·내년 / 7-4 앞으로 12개월 중 더 세심히 돌볼 달(표: 시기 / 먼저 살피는 곳 / 왜 / 이렇게 돌봐) + 가벼워지는 달 / 7-5 일상에서 할 수 있는 돌봄
